# Aptis Survival Kit

Tài liệu và công cụ hỗ trợ ôn luyện kỳ thi Aptis.

## Mục tiêu

Repository này tập hợp các tài liệu, chiến lược và bài luyện tập giúp việc chuẩn bị cho kỳ thi Aptis trở nên có hệ thống hơn.

## Trạng thái

Dự án đang được khởi tạo. Nội dung và cấu trúc sẽ được bổ sung trong các commit tiếp theo.

## Đóng góp

Mọi đề xuất cải thiện tài liệu, bài luyện tập hoặc công cụ đều được hoan nghênh. Vui lòng mở issue hoặc pull request để cùng phát triển dự án.
